## 規則

1. **語意切分一律以本資料夾的官方原檔為準**——`rag-data/` 的切塊文字必須逐字對得上原檔；不得以二手轉貼文字為語料來源。core 與 pending 兩庫的切塊皆以本檔為源頭，生效狀態依 manifest 判定。
2. 下載方式：全國法規資料庫法規頁面 →「下載」→ PDF 版。若直鏈（LawAllPDF.aspx?pcode=K0040012）被站台安全過濾擋下，改由頁面下載按鈕進入。
3. 檔名慣例：`道路交通管理處罰條例-全國法規資料庫-<下載日YYYYMMDD>.pdf`；放入後在本 README 登記：版本（修正日期）＋下載日＋SHA-256（溯源錨點）。
4. **metadata 溯源**：語料 metadata 的 `source_ref` 欄指向本資料夾原檔（檔名＋頁碼/條號定位）——回答可回查原檔＝端到端溯源。
5. 版本更新：法規若有新修正，新 PDF 另存（不覆蓋舊檔），並依 D4 流程記錄 `docs/ai-trace/d4-log.md` 評估切塊是否需重建。
