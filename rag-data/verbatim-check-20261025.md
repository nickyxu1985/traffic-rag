# 切塊逐字校訂報告（2026-10-25, Instinct）

## 方法
對小樣本 8 份切塊的【內容】本文，與官方原檔做去空白後的逐字包含比對。PDF 的項次阿拉伯數字（1、2…）為 Word 排版產物（官方 HTML 版條文無此數字），比對前剔除；切塊內 agent 加註之「（背景參照…）」引言行不計入本文。此為格式層差異，非文字出入。
